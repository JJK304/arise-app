# ARISE — Solo Leveling RPG Tracker

## Deploy auf Vercel

1. Gehe zu https://vercel.com und erstelle ein kostenloses Konto
2. Klicke auf "Add New Project"
3. Wähle "Import Git Repository" ODER direkt "Deploy" mit diesem Ordner
4. Bei "Framework Preset" wähle **Vite**
5. Klicke Deploy — fertig!

## Lokaler Test (optional)
```
npm install
npm run dev
```
